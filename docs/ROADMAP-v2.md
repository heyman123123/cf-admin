# cf-admin v2.0 需求文档：可视化建站引擎

> 版本：v2.0-draft
> 日期：2026-09-29
> 状态：待评审

---

## 一、背景与问题

当前 v1 版本已跑通"官网 SSR + CRM + 后台"的主链路，但官网侧存在三个硬伤：

| 问题 | 现状 | 用户痛感 |
|---|---|---|
| **无法新建页面** | 所有页面靠 SQL seed（`/`、/about、/saas`），后台只能编辑已有页面的 Block | 市场/运营想加一个"博客文章页"、"活动落地页"必须找开发改代码跑迁移 |
| **样式太简陋** | BlockRenderer 输出的是裸 HTML，内联只有一行全局 reset，没有任何视觉设计 | 官网看起来像 90 年代网页，完全不能对外用 |
| **配置不直观** | Block 编辑器是表单字段（填 title / content_json），看不到效果，改一个按钮颜色要猜 | 运营/市场不会用，必须懂 JSON |

v2 的核心目标：**让非技术人员在浏览器里，30 分钟搭出一个视觉合格、响应式良好的多页官网。**

---

## 二、目标与非目标

### 2.1 业务目标

1. 后台支持**完整的页面 CRUD**（新建/复制/删除/发布/设为首页）
2. 提供 **15+ 个专业设计的内容组件**（Block），每个都带桌面/平板/移动端三套预设
3. 提供**拖拽式可视化编辑器**（Canvas 实时预览），替代当前的纯表单
4. 输出**响应式**站点，在 360px / 768px / 1280px / 1920px 断点下都不破版
5. 提供**主题系统**（配色、字体、圆角、阴影），一键换肤

### 2.2 非目标（v2 不做）

- ❌ 用户自定义代码块（HTML/CSS 注入）——安全风险，v3 再说
- ❌ 多站点/多租户——单域单站
- ❌ 博客文章系统（独立的 posts 表 + 标签 + 评论）——v2.1
- ❌ i18n 多语言——v2.2
- ❌ A/B 测试——v3

| 角色 | 核心场景 |
|---|---|
| **市场运营** | 周五要上线一个新品落地页：新建页面 → 选 Hero 组件 → 拖入 Pricing → 填文案 → 发布 |

| **开发者** | 新增一个 Block 类型：在代码里加一个 React 组件 + schema → 自动出现在组件库 |

## 四、功能需求

### 4.1 页面管理（P0）

**用户故事：** 作为市场运营，我要在后台新建一个页面，不写代码。

- [ ] **新建页面**：输入 slug（如 `/launch-2026`）、标题、TDK，选择一个空白模板或从已有页面克隆
- [ ] **页面列表**：表格展示所有页面（slug / 标题 / 状态 / 更新时间 / 访问按钮）
- [ ] **复制页面**：一键克隆整个页面的所有 Block
- [ ] **删除页面**：软删除（is_published=0 + 标记 deleted），30 天后物理清理
- [ ] **设为首页**：把任意 slug 设为 `/` 指向的页面
- [ ] **页面状态**：草稿 / 已发布 / 已下线 三态切换
- [ ] **URL 冲突检测**：slug 重复时拒绝保存并提示

### 4.2 可视化编辑器 Canvas（P0）

**用户故事：** 作为运营，我要像搭积木一样拖组件，实时看到最终效果。

- [ ] **三栏布局**：
  - 左：组件库（可拖拽）
  - 中：Canvas 实时预览（iframe，按当前选中的设备尺寸渲染）
  - 右：选中组件的属性面板
- [ ] **设备切换**：顶部按钮切换 桌面 / 平板 / 手机 三种预览宽度（1280 / 768 / 375）
- [ ] **拖拽排序**：上下拖 Block 调整顺序，左右拖进容器（v2.1）
- [ ] **选中即配置**：点 Canvas 里的组件 → 右侧面板出对应表单
- [ ] **撤销/重做**：至少 50 步历史（v2.1）
- [ ] **自动保存**：每 3 秒未操作自动存草稿，关闭后不丢
- [ ] **发布/预览**：右上角"预览"按钮出带 token 的临时链接，"发布"按钮清 CDN 缓存

### 4.3 内容组件库（P0）

**用户故事：** 作为运营，我要选现成的好看组件，不用自己设计。

每个组件必须满足：
- 桌面/平板/手机三档响应式
- 配色继承主题 token，不写死色值
- 有至少 3 个预设样式（variant）

v2 必做组件清单（15 个）：

| # | 组件 | 说明 |
|---|---|---|
| 1 | **Hero Banner** | 大标题 + 副标题 + CTA 按钮 + 背景图/视频/渐变，左文右图 / 居中文案 / 全屏三种布局 |
| 2 | **Logo Cloud** | 一排客户 logo，自动灰度，hover 变彩色 |
| 3 | **Features Grid** | 2/3/4 列卡片，图标 + 标题 + 描述 |
| 4 | **Stats Counter** | 大数字滚动动画（10K+ 用户 / 99.9% 可用性） |
| 5 | **Pricing Table** | 三档价格卡，中间高亮，月付/年付切换 |
| 6 | **Testimonials** | 用户评价轮播，头像 + 姓名 + 职位 + 引用 |
| 7 | **FAQ Accordion** | 手风琴折叠问答 |
| 8 | **CTA Section** | 大色块背景 + 居中标题 + 单个大按钮 |
| 9 | **Contact Form** | 姓名/邮箱/留言 + Turnstile，提交后线索入库（复用现有流水线） |
| 10 | **Team Grid** | 头像 + 姓名 + 职位 + 社交链接 |
| 11 | **Blog List** | 文章卡片网格（v2.1 接 posts 表，v2 先静态） |
| 12 | **Video Embed** | YouTube / Bilibili / mp4 嵌入，封面图占位 |
| 13 | **Rich Text** | 富文本段落（标题/段落/引用/列表/图片） |
| 14 | **Divider** | 分割线（实线/虚线/带图标/带文字） |
| 15 | **Spacer** | 空距占位（上下间距可调） |

### 4.4 主题系统（P1）

**用户故事：** 作为运营，我要改一次主色，全站自动换肤。

- [ ] **全局主题面板**：后台侧栏"主题"入口
  - 主色（primary）、辅助色（accent）、背景色、文字色
  - 字体（系统字体 / Inter / Noto Sans SC）
  - 圆角大小（sm / md / lg / full）
  - 容器最大宽度（1200 / 1280 / 1440）
- [ ] 主题存 KV（`theme:current`），SSR 时注入 CSS 变量
- [ ] 提供 3 个预设主题：现代科技蓝 / 简约黑白 / 活力橙

### 4.5 响应式适配规则（P0）

每个 Block 的 content_json 里允许覆盖不同断点的配置：

```jsonc
{
  "block_type": "hero",
  "content_json": {
    "title": "在 30 分钟内上线官网",
    "desktop": { "layout": "left-image", "textAlign": "left" },
    "tablet":  { "layout": "left-image", "textAlign": "left" },
    "mobile":  { "layout": "stacked",   "textAlign": "center" }
  }
}
```

- SSR 输出时按断点生成对应的 class（如 `hero--mobile-stacked`）
- Tailwind 响应式前缀（`md:` `lg:`）作为底层实现
- 不允许出现横向滚动条（375px 下）

### 4.6 媒体库增强（P1）

- [ ] 图片上传后自动生成缩略图（R2 存原图 + KV 记尺寸）
- [ ] 媒体库支持搜索、按时间排序
- [ ] 拖拽图片到 Canvas 直接替换 Hero 背景

## 五、技术方案要点

### 5.1 数据模型变更

```sql
-- 新增：页面主题绑定
ALTER TABLE pages ADD COLUMN theme_id TEXT DEFAULT 'default';
ALTER TABLE pages ADD COLUMN template TEXT DEFAULT 'blank';  -- blank / landing / saas

-- page_blocks.content_json 结构升级
-- 旧：{ title, subtitle, imageUrl }
-- 新：{ 
--   "props": { ...通用属性 },
--   "variants": { "desktop": {...}, "tablet": {...}, "mobile": {...} }
-- }
```

### 5.2 前端编辑器架构

- Canvas 用 iframe 加载一个独立的 `editor-preview.html`，通过 postMessage 接收 Block 配置
- Block 组件用 React 写，同时编译两份：
  - 编辑器里：带选中框、拖拽手柄、属性面板
  - SSR 输出：纯静态 HTML + Tailwind class
- 复用同一套 schema（Zod）做属性面板表单自动生成

### 5.3 性能

- Canvas iframe 按需加载，不阻塞后台首屏
- Block 组件库做 code splitting，15 个组件分成 3 个 chunk
- 主题 CSS 用 CSS 变量，不内联大段样式

## 六、非功能需求

| 指标 | 目标 |
|---|---|
| Canvas 拖拽帧率 | ≥ 60fps |
| 后台首屏 LCP | < 2.5s（Pages CDN） |
| SSR TTFB | 维持 < 100ms（命中缓存） |
| 375px 横向滚动 | 0 |
| Block 配置保存延迟 | < 300ms |
| 编辑器兼容浏览器 | Chrome / Edge / Safari 最近两个大版本 |
